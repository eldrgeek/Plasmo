---
description: Run bd (Beads) commands for issue tracking
---

Execute the bd command that the user provides after `/bd`.

Examples:
- `/bd list` → Run `bd list`
- `/bd ready --json` → Run `bd ready --json`
- `/bd create "New task" -p 1` → Run `bd create "New task" -p 1`

Always show the full output of the command.
